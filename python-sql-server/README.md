# 🐍 Python + SQL Server

Este diretório reúne meus estudos sobre integração entre Python e SQL Server.

## Objetivo

Aprender a conectar aplicações Python ao SQL Server utilizando o Visual Studio Code, aplicando os conceitos estudados durante os cursos de Banco de Dados e Ciência de Dados.

## Tecnologias

- Python
- SQL Server
- SQL Server Management Studio (SSMS)
- Visual Studio Code
- Git
- GitHub

## Conteúdo

Este projeto será desenvolvido de forma progressiva, incluindo:

- Conexão com o banco de dados
- Consultas SQL utilizando Python
- Manipulação de dados
- Integração com Pandas
- Preparação de dados para análises futuras

## Banco utilizado

Todos os exemplos serão desenvolvidos utilizando o banco **EstudosDados**, criado durante meus estudos de SQL.
