# 📊 Databases and SQL for Data Science with Python

Este repositório registra minha jornada de aprendizado no curso **Databases and SQL for Data Science with Python**, oferecido pela IBM na Coursera.

O objetivo deste projeto é desenvolver habilidades em Banco de Dados, SQL e integração com Python para análise de dados e resolução de problemas reais.

---

# 🚀 Objetivos

- Aprender fundamentos de bancos de dados relacionais
- Desenvolver consultas SQL
- Trabalhar com filtros, JOINs e agregações
- Utilizar SQL para análise de dados
- Integrar SQL com Python
- Construir projetos práticos
- Criar um portfólio profissional no GitHub

---
