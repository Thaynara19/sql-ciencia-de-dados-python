# 📘 Diário de Aprendizado — SQL, SSMS, VS Code e GitHub

Hoje avancei bastante na prática com SQL Server utilizando o SSMS, VS Code e GitHub.

## 🛠️ O que pratiquei

- Criação de banco de dados e tabelas no SSMS
- Uso de `PRIMARY KEY` e `IDENTITY`
- Organização de exercícios em arquivos `.sql`
- Integração entre SSMS → VS Code → GitHub
- Uso de comandos Git no terminal

## 🔄 Fluxo que aprendi

1. Criar e testar a tabela no SSMS
2. Salvar o script SQL no VS Code
3. Organizar os exercícios em pastas do projeto
4. Utilizar Git para versionamento:
   
```bash
git add .
git commit -m "Mensagem"
git push
```

⚠️ Dificuldades encontradas

Durante o processo tive dificuldades com:

organização das pastas no projeto
conflito entre branch main e master
problemas de git pull, rebase e conflitos de merge
entender o diretório correto do Git

Mesmo com os erros, consegui resolver os conflitos e organizar corretamente o projeto.
