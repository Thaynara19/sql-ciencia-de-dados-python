# 💻 Aprendizados

Hoje ficou muito mais claro como funciona o fluxo completo de análise de dados utilizando Python e SQL.

Aprendi que:

- O Pandas pode importar arquivos CSV para DataFrames.
- Um DataFrame representa uma tabela em memória.
- O método `to_sql()` cria tabelas automaticamente em um banco SQLite.
- O método `read_sql()` permite executar consultas SQL e retornar o resultado em um DataFrame.
- O SQL Magic permite escrever consultas SQL diretamente dentro do Jupyter Notebook.
