- DISTINCT

- MIN()

## Pontos que acertei

- Consultas básicas utilizando SELECT.
- Filtros utilizando WHERE.
- Uso de BETWEEN para intervalos.
- Utilização de MAX(), MIN() e AVG().
- Combinação de condições utilizando AND.

## Dificuldades encontradas

### LIKE

Confundi a sintaxe correta.

Exemplo correto:

```sql
SELECT *
FROM cadastro
WHERE nome LIKE 'A%';
```

### COUNT()

Utilizei:

```sql
SELECT COUNT(pessoas)
FROM cadastro;
```

Quando o correto seria:

```sql
SELECT COUNT(*)
FROM cadastro;
```

### Atenção aos detalhes

Percebi que alguns erros aconteceram por:

- Digitação incorreta de colunas.
- Esquecer filtros na cláusula WHERE.
- Posicionar incorretamente o operador LIKE.
