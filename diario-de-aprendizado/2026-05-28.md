# 📘 Aprendendo ALTER TABLE no SQL

Hoje pratiquei comandos para alterar estruturas de tabelas no SQL Server utilizando `ALTER TABLE`.

## 🛠️ O que aprendi

- Adicionar novas colunas com `ADD`
- Remover colunas com `DROP COLUMN`
- Diferença entre alterar estrutura e alterar dados
- Executar comandos SQL diretamente pelo VS Code conectado ao SQL Server

## 📌 Exemplos praticados

### Adicionando coluna

```sql
ALTER TABLE teste
ADD professor VARCHAR(30); é para adicionar o professor na lista da tabela.
DROP COLUNM - é para excluir uma coluna.
DROP TABLE - excluir tabela
