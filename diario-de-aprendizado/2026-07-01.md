# 📚 Conteúdos estudados

## Conexão entre Python e SQL Server

Aprendi como criar uma conexão entre Python e SQL Server utilizando a biblioteca **pyodbc**.

Durante esse processo compreendi a função de cada parâmetro da conexão:

- `DRIVER` → Responsável por permitir a comunicação entre Python e SQL Server.
- `SERVER` → Nome da instância do SQL Server.
- `DATABASE` → Banco de dados que será acessado.
- `Trusted_Connection=yes` → Utiliza a autenticação do Windows.

Também entendi que essas informações permanecem no código e não precisam ser digitadas toda vez que o programa é executado.

# Primeiro programa conectado ao banco

Foi desenvolvido o primeiro programa realizando as seguintes etapas:

1. Importação das bibliotecas.
2. Criação da conexão com o SQL Server.
3. Criação da consulta SQL.
4. Execução da consulta utilizando o Pandas.
5. Impressão dos resultados.
6. Encerramento da conexão.

Estrutura utilizada:

```python
import pyodbc
import pandas as pd

conexao = pyodbc.connect(...)

consulta = "SELECT * FROM Alunos"

df = pd.read_sql(consulta, conexao)

print(df)

conexao.close()
```

# Conceitos compreendidos

## Import

Aprendi que o comando `import` importa bibliotecas para disponibilizar novas funcionalidades ao Python.

Exemplo:

- `pyodbc` → comunicação com o SQL Server.
- `pandas` → manipulação dos dados.

---

## Consulta SQL dentro do Python

Aprendi que a consulta SQL é armazenada em uma variável:

```python
consulta = "SELECT * FROM Alunos"
```

Essa linha apenas guarda o comando SQL.

A consulta só é realmente executada quando utilizamos:

```python
pd.read_sql()
```

---

## DataFrame

Compreendi que um **DataFrame** funciona como uma planilha do Excel dentro do Python.

Nele podemos:

- visualizar dados;
- realizar filtros;
- ordenar registros;
- calcular estatísticas;
- gerar gráficos futuramente.

# Dificuldades encontradas

Durante a prática encontrei alguns problemas importantes.

## Esquecendo de salvar o arquivo

O código estava correto, porém eu executava:

```powershell
python conexao.py
```

sem salvar o arquivo antes.

Após salvar (`Ctrl + S`), o programa passou a funcionar normalmente.

Esse erro reforçou a importância de sempre salvar o código antes da execução.

---

## Ordem da conexão

Também compreendi que a conexão só deve ser encerrada após todas as consultas serem executadas.

Ou seja:

```python
conexao.close()
```

deve ficar no final do programa.

# Git e GitHub
