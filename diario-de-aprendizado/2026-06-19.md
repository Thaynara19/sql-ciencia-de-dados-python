# 📅 2026-06-19 - Modelagem de Banco de Dados e INNER JOIN

## Objetivo

Dar continuidade ao projeto de banco de dados da escola, criando novas tabelas e aprofundando os relacionamentos entre elas.

## Conteúdo estudado

- Criação da tabela `Secretaria`
- Criação da tabela `Matriculas`
- Adição de chaves estrangeiras (`FOREIGN KEY`)
- Inserção de registros relacionados entre múltiplas tabelas
- Consultas utilizando `INNER JOIN` entre Alunos, Curso, Secretaria e Matriculas

## Aprendizados

- Entendi melhor como funcionam os relacionamentos entre tabelas.
- Aprendi que uma `FOREIGN KEY` só aceita valores que já existem na tabela de referência.
- Compreendi a importância de verificar os IDs antes de realizar inserções.
- Consegui montar consultas envolvendo quatro tabelas utilizando `INNER JOIN`.

## Dificuldades encontradas

- Erros ao criar relacionamentos por utilizar nomes incorretos de colunas.
- Conflitos de `FOREIGN KEY` causados por IDs inexistentes.
- Necessidade de revisar a estrutura das tabelas para identificar inconsistências.

## Evolução

Hoje consegui construir consultas mais completas e entender melhor a lógica dos relacionamentos em bancos de dados relacionais. Aos poucos, o uso de `INNER JOIN` está ficando mais natural e passei a interpretar as mensagens de erro do SQL Server para encontrar a causa dos problemas.
