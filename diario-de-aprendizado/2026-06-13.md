# Modelo Relacional

Aprendi que um banco de dados relacional é composto por várias tabelas que podem se relacionar entre si.

Cada tabela possui uma função específica, evitando a duplicação de informações e facilitando a organização dos dados.

Exemplo:

```text
Cursos
-------------------------
idcurso (PK)
nome
carga

        │
        │
        ▼

Alunos
-------------------------
id
nome
idcurso (FK)
```

Nesse exemplo, a tabela **Alunos** está relacionada à tabela **Cursos** por meio da coluna `idcurso`.

---

# Chave Primária (PRIMARY KEY)

A chave primária identifica cada registro de forma única.

Exemplo:

```sql
CREATE TABLE cursos (
    idcurso INT PRIMARY KEY,
    nome VARCHAR(50)
);
```

Cada curso possui um identificador único.

---

# Chave Estrangeira (FOREIGN KEY)

Aprendi que a chave estrangeira é responsável por criar o relacionamento entre duas tabelas.

No SQL Server, a sintaxe é praticamente igual à do MySQL.

Exemplo:

```sql
CREATE TABLE alunos (
    id INT PRIMARY KEY,
    nome VARCHAR(50),
    idcurso INT,
    FOREIGN KEY (idcurso)
    REFERENCES cursos(idcurso)
);
```

Também aprendi que é possível adicionar a chave estrangeira posteriormente utilizando:

```sql
ALTER TABLE alunos
ADD CONSTRAINT FK_Aluno_Curso
FOREIGN KEY (idcurso)
REFERENCES cursos(idcurso);
```

---

# INNER JOIN

Aprendi que o INNER JOIN é utilizado para unir informações de duas tabelas relacionadas.

Exemplo:

```sql
SELECT
a.nome,
c.nome AS Curso
FROM alunos AS a
INNER JOIN cursos AS c
ON a.idcurso = c.idcurso;
```

Resultado esperado:

| Aluno | Curso |
|--------|--------|
| João | HTML |
| Maria | Python |

---

# Utilização do AS

Aprendi que o comando `AS` pode ser utilizado para criar apelidos para colunas e tabelas.

Apelido para coluna:

```sql
SELECT nome AS NomeAluno
FROM alunos;
```

Apelido para tabela:

```sql
SELECT *
FROM alunos AS a;
```

Também é possível omitir o `AS`:

```sql
FROM alunos a
```

---

# Comparação entre MySQL e SQL Server

Durante os estudos percebi que a maior parte da sintaxe permanece igual.

| MySQL | SQL Server |
|--------|------------|
| AUTO_INCREMENT | IDENTITY(1,1) |
| RENAME TABLE | sp_rename |
| FOREIGN KEY | Igual |
| INNER JOIN | Igual |
| AS | Igual |

Isso mostra que os conceitos aprendidos podem ser aplicados em diferentes sistemas gerenciadores de banco de dados.
