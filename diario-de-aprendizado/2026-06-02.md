## O que estudei hoje

Hoje revisei comandos de consulta SQL e aprendi operadores lógicos utilizados para filtrar informações em tabelas.

## Operadores estudados

### AND

Retorna resultados apenas quando todas as condições são verdadeiras.

```sql
SELECT *
FROM curso
WHERE ano = 2015
AND carga = 40;
```

### OR

Retorna resultados quando pelo menos uma das condições é verdadeira.

```sql
SELECT *
FROM curso
WHERE ano = 2015
OR carga = 40;
```

### BETWEEN

Utilizado para buscar valores dentro de um intervalo.

```sql
SELECT *
FROM curso
WHERE ano BETWEEN 2011 AND 2015;
```

### IN

Utilizado para buscar valores específicos em uma lista.

```sql
SELECT *
FROM curso
WHERE ano IN (2010, 2015, 2018);
```

## Aprendizados

* `AND` exige que todas as condições sejam verdadeiras.
* `OR` exige que apenas uma condição seja verdadeira.
* `BETWEEN` retorna todos os valores dentro de um intervalo.
* `IN` retorna apenas os valores informados na lista.
