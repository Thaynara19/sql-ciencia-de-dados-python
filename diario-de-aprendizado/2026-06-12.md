# Dificuldades encontradas

Durante a resolução percebi que ainda preciso praticar alguns comandos específicos.

## LIKE

Confundi a posição correta da sintaxe.

Escrevi:

```sql
WHERE LIKE nome '%A';
```

O correto é:

```sql
WHERE nome LIKE '%A';
```

---

## UPDATE

Ainda confundo a sintaxe utilizada no SQL Server.

Escrevi:

```sql
UPDATE TABLE alunos
WHERE ...
SET ...
```

O correto é:

```sql
UPDATE alunos
SET ...
WHERE ...;
```

---

## DELETE

Confundi a exclusão de registros com alteração da estrutura da tabela.

Revisão:

```sql
DELETE FROM alunos
WHERE nome = 'Rafael';
```

---

## TRUNCATE

Esqueci a sintaxe correta.

Correto:

```sql
TRUNCATE TABLE alunos;
```

---

## GROUP BY

Percebi que muitas vezes esqueço de exibir a coluna utilizada no agrupamento.

Exemplo correto:

```sql
SELECT cidade, COUNT(*)
FROM alunos
GROUP BY cidade;
```

---

## HAVING

Foi o conteúdo que apresentou maior dificuldade.

Eu lembrava da lógica, mas esquecia a sintaxe.

Exemplo correto:

```sql
SELECT cidade, COUNT(*)
FROM alunos
GROUP BY cidade
HAVING COUNT(*) > 2;
```

---

# Aprendizados

Durante a correção consegui reforçar alguns conceitos importantes.

## WHERE

Filtra registros antes do agrupamento.

## GROUP BY

Agrupa registros que possuem o mesmo valor.

## HAVING

Filtra os grupos após o agrupamento.

## ORDER BY

Ordena o resultado final.
