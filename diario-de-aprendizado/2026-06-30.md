# 📅 Diário de Aprendizado - Python + SQL Server

## 📚 O que estudei hoje

Hoje iniciei a preparação do ambiente para integrar **Python** com **SQL Server**, acompanhando o módulo sobre acesso a bancos de dados utilizando Python.

### 🐍 Configuração do ambiente

- Instalação e configuração do Python.
- Configuração do Visual Studio Code para desenvolvimento em Python.
- Criação do ambiente virtual (`.venv`).
- Instalação das bibliotecas iniciais:
  - `pyodbc`
  - `pandas`
- Criação do arquivo `requirements.txt`.
- Organização da estrutura do projeto `python-sql-server`.
- Configuração do `.gitignore` para evitar o envio do ambiente virtual ao GitHub.

---

## 💡 Conceitos aprendidos

Durante as aulas compreendi melhor como funciona a comunicação entre Python e bancos de dados.

Aprendi sobre:

- APIs de conexão com bancos de dados.
- Objetos de conexão (`Connection`).
- Objetos de cursor (`Cursor`).
- Diferença entre SQL executado no Jupyter e SQL executado diretamente pelo Python.
- Comandos mágicos (`%` e `%%`) utilizados apenas no Jupyter Notebook.
- Fluxo de integração entre Python, SQL Server e Pandas.

Também entendi que, para o meu projeto, utilizarei o **Visual Studio Code + SQL Server Management Studio (SSMS)** em vez do Jupyter Notebook, mantendo um ambiente mais próximo do utilizado no mercado.
