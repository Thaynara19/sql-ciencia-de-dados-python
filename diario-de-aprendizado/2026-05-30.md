# 📘 Diário de Aprendizado - SQL Server (Revisão)

## O que estudei hoje

Hoje foi um dia focado em revisão dos comandos SQL que já havia praticado anteriormente, reforçando conceitos importantes sobre estrutura de tabelas.

### Comandos revisados

* `ALTER TABLE` para modificar tabelas existentes.
* `ADD` para adicionar novas colunas.
* `DROP COLUMN` para remover colunas.
* `sp_rename` para alterar o nome de tabelas.
* `PRIMARY KEY` para definir chaves primárias.
* `UPDATE` para alterar valores de registros existentes.
* `DELETE` para remover registros da tabela.

### Aprendizados importantes

* Uma coluna que será chave primária não pode permitir valores `NULL`.
* O SQL Server possui diferenças em relação a outros bancos de dados, como MySQL e PostgreSQL.
* Nem todos os comandos encontrados na internet funcionam no SQL Server, sendo importante verificar a sintaxe específica do banco utilizado.
* Aprendi a realizar alterações estruturais diretamente por comandos SQL, sem depender apenas da interface gráfica do SSMS.

### Dificuldades encontradas

* Erros ao definir uma chave primária em uma coluna que permitia valores nulos.
* Diferenças de sintaxe entre bancos de dados.
* Entender quando utilizar comandos para alterar a estrutura da tabela e quando utilizar comandos para alterar os dados.

### Evolução

Estou conseguindo criar, modificar e organizar tabelas utilizando comandos SQL, além de registrar meus exercícios no VS Code e versioná-los utilizando Git e GitHub.
