# 📅 2026-06-24 - Python para Banco de Dados: Planejamento e dúvidas

## Objetivo

Iniciar os estudos sobre conexão entre Python e bancos de dados relacionais, compreendendo como essa integração será utilizada nos próximos módulos do curso.

## Conteúdo estudado

- Introdução à Python DB-API.
- Objetos de conexão (`Connection`).
- Objetos de cursor (`Cursor`).
- Conceito de APIs para acesso a bancos de dados.
- Funcionamento da comunicação entre Python e um SGBD.

## Principais dúvidas esclarecidas

### Jupyter Notebook ou VS Code?

O curso utiliza o **Jupyter Notebook**, porém optei por continuar utilizando o **Visual Studio Code** como ambiente principal de desenvolvimento.

Foi definido que:

- O VS Code continuará sendo utilizado para desenvolvimento em Python e SQL.
- O SQL Server Management Studio (SSMS) continuará sendo utilizado para administração do banco de dados.
- O Jupyter será estudado posteriormente, principalmente para análises de dados, visualizações e projetos envolvendo Pandas e Machine Learning.
