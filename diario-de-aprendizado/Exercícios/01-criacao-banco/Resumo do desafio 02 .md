# 🎓 Academia DBA - Desafio 02

## 📚 Resumo do desafio

Neste desafio continuei desenvolvendo o banco de dados **EscolaDB**, reforçando os principais comandos SQL através de exercícios práticos.

### 📝 Questões desenvolvidas

### Questão 1
Criação da tabela **Professores** utilizando:

- `CREATE TABLE`
- `PRIMARY KEY`
- `IDENTITY`
- `NOT NULL`

### Questão 2
Inserção de registros na tabela utilizando:

- `INSERT INTO`
- `VALUES`

### Questão 3
Consulta de todos os registros:

- `SELECT *`

### Questão 4
Consulta de colunas específicas:

- `SELECT nome, disciplina`

### Questão 5
Filtragem de registros utilizando:

- `WHERE`

### Questão 6
Atualização de dados utilizando:

- `UPDATE`
- `SET`
- `WHERE`

### Questão 7
Exclusão de registros utilizando:

- `DELETE`
- `WHERE`

### Questão 8
Contagem de registros utilizando:

- `COUNT(*)`

### Questão 9
Criação da tabela **Turmas**.

### Questão 10
Inserção de registros na tabela **Turmas**.

## 💡 Conhecimentos reforçados

Durante este desafio pratiquei:

- CREATE TABLE
- PRIMARY KEY
- IDENTITY
- NOT NULL
- INSERT INTO
- SELECT
- WHERE
- UPDATE
- DELETE
- COUNT

## 🚀 Evolução

Neste desafio consegui escrever praticamente todos os comandos sem consultar materiais, reforçando minha memória prática em SQL Server e melhorando minha organização na escrita das consultas.

Próximo objetivo: aprender e praticar o comando **ORDER BY**, continuando a evolução do banco **EscolaDB**.
