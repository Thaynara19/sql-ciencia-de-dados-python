# 🎯 Objetivo

Neste primeiro desafio pratiquei a criação de um banco de dados utilizando SQL Server.

O foco foi aprender a criar um banco, selecionar o banco correto e criar minha primeira tabela utilizando boas práticas de modelagem.

Banco utilizado:

**EscolaDB**

---

# 📝 Exercícios

## Questão 1

Criar o banco de dados **EscolaDB**.

### Conceito praticado

- CREATE DATABASE

---

## Questão 2

Selecionar o banco de dados criado.

### Conceito praticado

- USE

---

## Questão 3

Criar a tabela **Alunos** contendo:

- id
- nome
- idade
- cidade

### Conceitos praticados

- CREATE TABLE
- PRIMARY KEY
- IDENTITY
- NOT NULL
- VARCHAR
- INT

---

# 📚 Novo conhecimento

Durante este desafio aprendi:

## CREATE DATABASE

Cria um novo banco de dados.

```sql
CREATE DATABASE EscolaDB;
```

## USE

Seleciona o banco onde serão executados os comandos.

```sql
USE EscolaDB;
```

## CREATE TABLE

Utilizado para criar tabelas dentro do banco.
